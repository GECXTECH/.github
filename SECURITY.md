# Security Policy

## Supported Versions

We actively maintain the latest major version of our open-source projects. Older versions receive security updates only when feasible.

## Reporting a Vulnerability

Please report security vulnerabilities by emailing:

ke.wang@gecacademy.cn

We take all security reports seriously. You can expect an initial response within 3 business days. Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- Your assessment of potential impact
- Any relevant screenshots or code snippets

Do not disclose the vulnerability publicly (e.g., in issues, pull requests, or social media) until we have addressed it.

## Security Controls

- All organization members are required to use two-factor authentication
- Private repositories are not forked by default
- Secrets and API keys must never be committed to source code
